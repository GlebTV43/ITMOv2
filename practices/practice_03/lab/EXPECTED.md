**Эталон:**

```python

```

Тест подтверждает: `test_service.py:13-15`:

## Дополнительный демо-вопрос (для make demo)

**Вопрос:** Что происходит при двойной подписке одного имени, например «Ann» и « Ann » (с пробелом)?

**Эталон:**
- `subscribe("Ann")` — добавляет `"Ann"` в set (service.py:7: `subscribers.add(name.strip())`)
- `subscribe(" Ann ")` — `name.strip()` = `"Ann"`, добавляет то же значение
- Итог: `len(subscribers) == 1` — дубликат не создаётся

`test_service.py:17-20` покрывает дубликаты для одинакового имени `"Ann"`.
Пробельный вариант ` Ann ` не покрыт отдельным тестом, но логика strip() гарантирует то же поведение.
