# Mini Shop: Ключевые моменты для проверки

1. **Сессии и владельцы** — необходимо проверять.
2. **Использование параметров SQL** — обязательно требуется.
3. **Цена каталога и разрешённые пути** — должны находиться в этих пределах.
4. **Модель не предоставляет серверу полномочий** — ограничение доступа.
5. **Отзывы недоверенные** — нельзя принимать на доверие без проверки.
