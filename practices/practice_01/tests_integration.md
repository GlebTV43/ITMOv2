# Integration-проверки

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| API → ReviewService | отсутствующее поле `diff` приводит к исключению | POST `/api/reviews` с `{}` | контролируемый 4xx; сервис не отвечает необработанным 500 | I-01 |
| ReviewService → LLM | LLM недоступна/таймаут | mock/fake LLM бросает timeout | API возвращает контролируемую ошибку; причина логируется без секрета | I-02 |
| Prompt Builder → LLM | Context Pack не попал в запрос | перехватить prompt через fake LLM | prompt содержит ограничения: ≤3 риска, доказательства, human decision | I-03 |
| LLM → Result Validator | модель вернула нарушение формата | fake LLM возвращает 5 общих советов | нарушение обнаружено до показа как валидного результата | I-04 |
| API → ReviewService → LLM | корректный diff | POST с `TRAINING_PR.diff` через тестовый клиент и fake LLM | 2xx и структурированный черновик ревью | I-05 |

Для воспроизводимости внешнюю LLM в CI заменяем fake/mock реализацией; отдельный smoke-тест с реальной моделью запускается вручную и не является обязательным для детерминированного CI.

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): `P1-10`.
- Что проверил студент и какие исправления поручил агенту: разделил детерминированные интеграционные тесты и необязательный smoke с реальной LLM; добавил таймаут как отказ внешней зависимости.
