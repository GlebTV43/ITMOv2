# P1-01 — baseline review

## Входной запрос

```text
Ниже diff учебного PR. Посмотри PR и найди проблемы.
```

## Ответ baseline

Изменение добавляет метод `ReviewService.review`, который передаёт diff в LLM, и HTTP endpoint `POST /api/reviews`.

Потенциальные проблемы:

1. В `app/api.py` используется `payload["diff"]`. Если поле отсутствует, возникнет `KeyError`, который, если его не обработать глобально, приведёт к ошибке сервера. Нужна валидация входа.
2. Нет явной проверки пустого или слишком большого diff. Очень большой вход может увеличить задержку и стоимость обращения к LLM.
3. Вызов `self.llm.generate(prompt)` не показывает обработки ошибки или таймаута внешней модели; исключение может подняться до API.

Стоит добавить тесты на отсутствие `diff`, пустой diff и ошибку LLM.

## Студентская оценка

Ответ нашёл важную проблему с `payload["diff"]`, но он недостаточно строгий: нет точных ссылок на строки/фрагменты, часть выводов сформулирована без разделения «доказано diff» и «гипотеза о production-поведении». Проверки перечислены общо.
