# RAG

- **Инструмент / модель:** gpt-5.6 Sol
- **Вопрос к источникам:** какие требования к нагрузочному плану можно подтвердить уже имеющимися артефактами, не добавляя внешние и неподтверждённые SLA?

## Разрешённые источники

| Файл или документ | Зачем нужен | Какой фрагмент используем |
|---|---|---|
| [`../../practice_01/context.md`](../../practice_01/context.md) | определить известные и неизвестные ограничения | «Что пока неизвестно»: max diff, модель и SLA |
| [`../../practice_01/adr.md`](../../practice_01/adr.md) | проверить архитектурное требование к входу | «Решение»: явная входная модель и ограничение размера |
| [`../../practice_01/tests_integration.md`](../../practice_01/tests_integration.md) | согласовать нагрузочный стенд с интеграционными тестами | fake/mock LLM в CI и timeout-сценарий I-02 |
| [`../../practice_01/TRAINING_PR.diff`](../../practice_01/TRAINING_PR.diff) | не приписывать текущему коду несуществующую валидацию | endpoint принимает `payload: dict`, локальной проверки diff в diff нет |

## Запрос

```text
Ответь только по четырём разрешённым источникам выше.
Для каждого существенного правила tests_load.md укажи, каким источником оно подтверждается.
Если источник не подтверждает числовое значение или production SLA, не дополняй его из общих знаний: пометь это как неизвестное или blocked.
```

## Ответ со ссылками на источники

- Fake/mock LLM допустим и уже нужен для воспроизводимого CI: [`tests_integration.md`](../../practice_01/tests_integration.md), текст после таблицы.
- Timeout внешней зависимости — подтверждённый integration-сценарий I-02: [`tests_integration.md`](../../practice_01/tests_integration.md).
- Ограничение размера входа желательно архитектурно, но его значение не задано: [`adr.md`](../../practice_01/adr.md) + [`context.md`](../../practice_01/context.md).
- Production model, quotas и SLA нельзя вывести из текущих материалов: [`context.md`](../../practice_01/context.md), раздел «Что пока неизвестно».
- По `TRAINING_PR.diff` видно отсутствие локальной input validation в изменённом endpoint, но нельзя доказать отсутствие внешних gateway/queue/timeout механизмов: [`TRAINING_PR.diff`](../../practice_01/TRAINING_PR.diff).

## Что изменили в исходном артефакте

- **Файл и раздел:** [`tests_load.md` → «Трассировка требований»](../../practice_01/tests_load.md#трассировка-требований).
- **Изменение:** добавлена таблица «утверждение → подтверждение», а provider scenario вынесен в `blocked` до появления источника.
- **Как проверили ссылки:** все ссылки относительные, ведут на файлы из того же ZIP; утверждения вручную сопоставлены с соответствующими разделами.
- **Что отклонили как неподтверждённое:** любые внешние нормы по RPS, latency, токенам и квотам, которых нет в разрешённых источниках.
