# Chain of Verification

- **Инструмент / модель:** gpt-5.6 Sol
- **Проверяемый черновик или утверждение:** исходная версия `tests_load.md` утверждала учебный профиль `20 RPS, 2 минуты, p95 < 300 мс` и одновременно говорила, что production SLA неизвестен.

## Запрос на проверку

```text
Проверь текущий tests_load.md отдельно от его переписывания.
Сначала сформулируй вопросы, которые позволяют подтвердить каждый числовой предел и каждое утверждение о стенде.
Проверь вопросы только по context.md, adr.md и tests_integration.md.
После проверки дай исправленный вариант только тех утверждений, которые были неподтверждёнными.
```

## Вопросы и результаты проверки

| Вопрос | Источник или проверка | Результат |
|---|---|---|
| Есть ли подтверждённое требование на 20 RPS? | `context.md`, `problem.md`, `adr.md` | Нет. Production RPS нигде не задан. |
| Есть ли подтверждённый SLA `p95 < 300 мс`? | `context.md`, раздел «Что пока неизвестно» | Нет. Модель и SLA прямо указаны как неизвестные. |
| Можно ли использовать fake LLM для воспроизводимого теста? | `tests_integration.md`, текст после таблицы | Да. Для CI уже выбрана fake/mock реализация. |
| Известен ли конкретный лимит размера diff? | `context.md`; `adr.md` | Нет. ADR требует ограничение, но значение не определено. |
| Можно ли доказать отсутствие глобального timeout/queue механизма по `TRAINING_PR.diff`? | `TRAINING_PR.diff` | Нет. Diff показывает только изменённый код и не доказывает отсутствие инфраструктуры вне него. |

## Исправленный результат

- `20 RPS` и `p95 < 300 мс` не называются production-требованиями.
- Для сравнения производительности сначала собирается baseline на текущем стенде.
- Числа конкуренции остаются учебными параметрами эксперимента и явно так маркируются.
- Сценарий превышения размера diff имеет статус `blocked`, пока не появится фактический `MAX_DIFF_BYTES`.
- Нагрузочный тест внешнего provider также `blocked` до выбора модели, квот и SLA.

## Что изменили в исходном артефакте

- **Файл и раздел:** [`tests_load.md` → «Границы выводов»](../../practice_01/tests_load.md#границы-выводов).
- **Изменение:** добавлено явное различие между учебными параметрами, измеренным baseline и подтверждёнными production-требованиями.
- **Что отклонили:** прежние числовые пороги как якобы обязательный SLA.

Скрытые рассуждения модели не сохранялись; здесь приведены только вопросы, найденные подтверждения и исправленный результат.
