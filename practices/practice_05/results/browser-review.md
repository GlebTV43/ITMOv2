# Browser verification

Дата: 2026-10-30. Реальный in-app browser, http://127.0.0.1:8765/.
Действия выполнены через видимые поля и кнопки; POST не подменялся вызовом API.

| Шаг | Ожидание | Наблюдение |
|---|---|---|
| Открыть / | Пустое состояние, подписанная форма | «Пока нет подписчиков», поле «Имя подписчика» |
| Ввести `  Анна  `, нажать Подписать | Одна нормализованная запись | URL /?result=added, «Подписчик добавлен», строка Анна, счётчик 1 |
| Ввести Анна повторно | Без дубля | /?result=duplicate, «Уже подписан», счётчик 1 |
| Ввести три пробела | Ошибка без изменения | /subscribe, «Введите непустое имя», пробелы в поле, Анна осталась |
| Нажать Отписать Анна | Удаление выбранной записи | /?result=removed, «Подписчик удалён», пустой список, счётчик 0 |
| Снова подписать Анну | Итоговый вид для демонстрации | /?result=added, одна строка Анна |

Скриншоты: [ошибка](browser-error.png), [панель](browser-panel.png).
Просмотр итогового PNG подтвердил читаемую форму и список без обрезания.
HTTP-границы/повреждённые запросы отдельно проверены автоматическими тестами;
не выдаём их за ручные браузерные шаги.
