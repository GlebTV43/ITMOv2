# Независимая сверка команды UI до реализации

Дата: 2026-10-30. Роль: отдельный агент команды UI.
Вход: `ui.before.md`, `ui.spec.md`, `logic.spec.md`, `contract.md` и публичное
поведение `Registry` из практики 4. На момент проверки новой реализации нет.
Общий контракт уже согласован пользователем в основном чате.

## Ожидание → сверка → решение

| Вопрос исходной UI-спецификации | Сверка с контрактом и Registry | Решение для UI |
|---|---|---|
| Как вызывать действия? | Контракт задаёт серверные формы POST и 303 | Не придумывать JSON API и клиентский JavaScript |
| Что означает повтор? | Методы возвращают False без исключения | Сообщения «Уже подписан» и «Подписчик не найден» — нормальные исходы |
| Где нормализовать? | Registry выполняет strip до проверки длины | Передавать исходный name; не ставить maxlength=80 и не обрезать ввод |
| Что показывать при ошибке имени? | ValueError не меняет состояние | Текущий список, русская ошибка и исходное введённое имя |
| Как обрабатывать HTML в имени? | Registry допускает такие строки | Экранировать текст списка и значение скрытого поля формы |
| Что после перезапуска? | Registry хранится только в памяти | Не обещать сохранение подписчиков |

## Уточнения UI-спецификации

Добавлен явный сценарий повторной отписки, чтобы покрыть четвёртый исход
общего контракта. Уточнена UTF-8-отправка поля без клиентской нормализации.
Разделены неверное имя и повреждённая форма: сохранять значение можно,
когда получено одно корректно разобранное поле; при нескольких name UI
не выбирает произвольное значение для повторного показа.

Эти уточнения не меняют HTTP-контракт, правила Registry и границы фичи.
Исходная `ui.before.md` сохранена без правок. Код команда UI не писала.

Команда логики независимо подтвердила эти решения в обмене сообщениями агентов.
Дополнительно согласованы: лишние поля отклоняются как нарушение формы из одного
`name`; код сообщения после 303 выбирается из фиксированного набора. Неизвестный
код из query не отображается как произвольный текст пользователя.

## Итог

Противоречий между UI, общим контрактом и публичным API Registry не найдено.
Реализация должна доказать основной путь, повтор, ошибку/границу и безопасное
отображение имени тестами и браузерным демо. Этот документ — сверка требований,
а не утверждение об успешной проверке ещё не написанной реализации.

## Post-implementation: независимая проверка UI

Дата: 2026-10-30. Проверены `lab/view.py`, `lab/web.py` и
`lab/tests/test_http.py` по согласованным UI-спецификации и контракту.
Исходный код при проверке не менялся.

| Ожидание | Факт и доказательство |
|---|---|
| Поле с подписью и пустое состояние | `label for="name"`, `input id="name"`, точный текст пустого состояния; `test_empty_page_has_labelled_form_and_empty_state` |
| Формы работают без JS и не ужесточают длину | POST-формы с `accept-charset="UTF-8"`, без maxlength и скриптов; `test_form_roundtrip_subscribe_and_unsubscribe`, `test_ui_does_not_truncate_name_before_server_normalisation`, `test_padded_eighty_character_name_is_accepted` |
| HTML в имени остаётся текстом | `html.escape(..., quote=True)` в списке, hidden input, aria-label и восстановленном вводе; `test_user_markup_is_text_in_names_and_hidden_fields`, `test_invalid_input_is_escaped_when_redisplayed` |
| Ошибка сохраняет состояние и корректно разобранный ввод | Ответ 400, роль alert, исходный name; `test_invalid_names_preserve_state_and_input_on_both_actions` |
| Повреждённая форма не выбирает произвольное имя | Ответ 400 с пустым полем; `test_malformed_form_is_rejected_before_mutation` |
| Все четыре исхода различимы | Фиксированные сообщения added/duplicate/removed/missing; отдельные HTTP-тесты добавления, дубля, удаления и отсутствия |
| После успешного POST обновление страницы безопасно | 303 с Location; `test_refresh_after_redirect_does_not_change_state` |

Дополнительно статически проверены `lang="ru"`, заголовки разделов,
`aria-labelledby`, `aria-describedby`, `aria-invalid` для ошибки,
`role="status"` для результата и видимая CSS-индикация клавиатурного фокуса.
Это проверка структуры доступности, не полноценный аудит экранным диктором.
