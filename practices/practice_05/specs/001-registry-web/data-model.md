# Data Model

## Subscriber
`name: str`, уникальность чувствительна к регистру, strip перед сравнением.
Нормализованная длина 1–80 Python Unicode-символов. TypeError/ValueError
возникают до мутации. Данные принадлежат исходному Registry.

## ActionResult
Whitelist: added, duplicate, removed, missing. Это транспортные коды сообщений,
а не имена подписчиков. Неизвестный код не отображается как текст.

## PageState
Отсортированный снимок names, сообщение, ошибка и исходное корректно
декодированное имя для исправления. В malformed-form поле остаётся пустым.
GET не мутирует состояние; нормальный POST завершает 303; отклонённый POST
возвращает страницу с прежним снимком. Новый сервер создаёт пустой Registry.
