# Команда логики — исходная спецификация

Статус: исходный проект до согласования с командой UI.

Переиспользовать Registry из практики 4. subscribe/unsubscribe возвращают bool;
names возвращает отсортированный снимок. Неверный тип вызывает TypeError,
пустое имя и длина более 80 символов — ValueError. Проверка до изменения данных.

Открытые вопросы: передача исключений интерфейсу, адреса действий, HTTP-статусы,
время жизни экземпляра Registry и отображение результата False.
