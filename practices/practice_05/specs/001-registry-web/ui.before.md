# Команда UI — исходная спецификация

Статус: исходный проект до согласования с командой логики.

Пользователь видит список подписчиков, вводит имя и нажимает «Подписать».
У каждого подписчика есть кнопка «Отписать». После действия список обновляется.
Ошибки показываются рядом с формой. Пустой список имеет отдельную подсказку.

Открытые вопросы: формат обмена, обработка повторной подписки, нормализация,
ограничение длины, сохранение списка после перезапуска.
