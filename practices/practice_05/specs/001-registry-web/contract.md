# Общий контракт

Статус: согласован пользователем в чате 2026-10-30 до реализации.

## Границы

Одна фича: локальная веб-панель существующего реестра. Python stdlib,
серверный HTML, обычные формы без JavaScript и внешних зависимостей.
Код практики 4 используется напрямую, не копируется и не меняется.
Запуск только на 127.0.0.1. Один процесс, один Registry в памяти.
База данных, авторизация, облачный деплой и новые правила имён вне задачи.

## Вызовы и данные

| Запрос | Результат |
|---|---|
| GET / | 200, HTML со снимком Registry.names() и формой |
| POST /subscribe, поле name | subscribe(name), 303 на / с кодом результата |
| POST /unsubscribe, поле name | unsubscribe(name), 303 на / с кодом результата |
| Неверное имя или тело формы | 400, HTML с ошибкой, состояние сохранено |
| Неизвестный путь | 404 |

POST принимает application/x-www-form-urlencoded в UTF-8 с одним полем name.
Отсутствующее/повторяющееся поле отклоняется. Предел тела — 4096 байт;
превышение — 413, неподдерживаемый Content-Type — 415.
Имя — Unicode-строка: strip, затем непустота, затем длина <=80 символов.
Браузер не вводит собственную более строгую нормализацию.
Любой пользовательский текст экранируется в HTML, включая значения атрибутов.

## Состояния и сообщения

Новая подписка: «Подписчик добавлен». Повтор: «Уже подписан».
Удаление: «Подписчик удалён». Отсутствующий: «Подписчик не найден».
Оба результата False — нормальный идемпотентный исход, не HTTP-ошибка.
Пустой список: «Пока нет подписчиков». Ошибка имени: русское сообщение
о пустом имени или превышении 80 символов; не показывать traceback.
После перезапуска сервера список пуст. После обновления страницы POST
не повторяется благодаря перенаправлению 303.

## Приёмка

1. Из пустой панели подписать `  Анна  `: в списке ровно `Анна`.
2. Повторная подписка не создаёт дубль; отписка удаляет только выбранное имя.
3. Пустое имя и 81 символ отклоняются без изменения списка; 80 допустимы.
4. HTML в имени отображается текстом; снимок отсортирован и независим.
5. Регрессионные тесты практики 4 проходят; HTTP-сценарий выполняется
   против настоящего локального сервера; браузерное демо проверяет формы.
