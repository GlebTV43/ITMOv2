# HTTP Contract

Авторитетный согласованный документ: [contract.md](../contract.md).
Маршруты и статус-коды не дублируются здесь, чтобы не создать две версии.

Уточнения команд: отсутствующий, повторный или дополнительный form-field,
невалидный Content-Length/UTF-8/percent encoding дают 400 до Registry.
Content-Type допускает `application/x-www-form-urlencoded` с необязательным
`charset=utf-8`. Результаты 303: `/?result=added|duplicate|removed|missing`.
Неизвестный result игнорируется. Предел 4096 байт включает тело до декодирования.
Имя сохраняется на странице ошибки только после корректного разбора формы.
Все нормальные исходы используют одинаковый PRG; GET / ничего не меняет.
